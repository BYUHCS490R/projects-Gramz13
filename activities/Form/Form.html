  1. The form tag has an "action" attribute. What does it do?
  2. The form tag has a "method" attribute. What does it do?
  3. What is the difference between a "POST" and a "GET"?
  4. What are the different ways to style your form?
  5. How does flex help for both Desktop and Mobile phones?
  • The action attribute in a form tag specifies the URL where the form data is sent when the form is submitted.
  • The method attribute defines how the form data is sent to the server, usually using GET or POST.
  • The difference is that GET sends data in the URL while POST sends data in the request body.
  • You can style a form using CSS by changing colors, fonts, spacing (margin and padding), borders, input sizes, and adding effects like hover or focus styles.
  • Flexbox helps by making layouts flexible, so form elements can align in rows for desktop screens and easily stack into columns for mobile screens, improving responsiveness and usability.
