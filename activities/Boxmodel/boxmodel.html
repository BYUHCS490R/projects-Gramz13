Box Model

Engagement

  1. What is the difference between block tags and inline tags?
  2. What is the margin, border, and padding?
  3. What are units of measurement you can use in CSS?
  4. When would you use figure tag?

Answers

  1. Block tags start on a new line and take up the full width of the page, while inline tags stay on the same line and only take up as much space as needed. Block elements are usually used to structure the page, and inline elements are used to style or format parts of text.
  2. Margin, border, and padding are parts of the CSS box model. Padding is the space between the content and the border, the border is the line around the content, and the margin is the space outside the border that separates the element from other elements.
  3. Absolute units include px (pixels), cm (centimeters), mm (millimeters), in (inches), pt (points), and pc (picas), while relative units include %, em, rem, vw (viewport width), vh (viewport height), vmin, and vmax, which adjust based on screen size or parent elements.
  4. You use the figure tag when you want to group media content like an image, chart, diagram, or code snippet with a caption. It is commonly used with the figcaption tag to provide a description for the content.
