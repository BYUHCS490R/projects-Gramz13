Answers

  • Normal flow is the default layout in HTML where block elements stack vertically and inline elements appear side by side in the order they are written.
  • Float moves an element to the left or right so text can wrap around it, and you need to clear it to prevent layout problems because floated elements are removed from normal flow.
  • Relative moves an element from its original position, absolute positions it relative to the nearest positioned ancestor, and fixed keeps it in the same place on the screen even when scrolling.
