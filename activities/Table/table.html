QUESTIONS

  1. When do you use a table?
  2. When do you not use a table?
  3. When do you need to do extra work for table accessibility?

ANSWERS

  • When you need to display data that belongs in rows and columns such as statistics, Schedules, Financial Data, Surver Results, and Comparison Charts
  • Do not use table for page layout or design or if you are not showing statistics or data.
  • Extra accessibility work is needed when tables are complex or large so screen readers can understand the headers and relationships between data.
