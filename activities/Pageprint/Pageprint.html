  1. Why is the viewport mea tag important?
    — The viewport meta tag is important because it helps a webpage display correctly on different screen sizes, especially on mobile devices.
  2. How can you adjust the CSS for printing?
    — You can adjust it by using @media print or @media ONLY print
  3. When would you want to adjust the CSS for printing?
    — You would adjust the CSS for printing when you want a clean, organized, and ink-friendly version of webpage for users to pring.
  4. When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?
    — If the same tag is selected twice with different rules, the last CSS rule written takes priority because of the CSS cascade.
  5. How do you change the CSS for a web page displayed on a phone?
    — You can change the CSS for a web page displayed on a phone by using CSS media queries that apply styles based on the screen size.
