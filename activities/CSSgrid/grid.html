  1. Please describe the parent-child relationship in HTML and why it becomes essential when using flex and grid.
  2. What are the two main differences between CSS Grid and CSS Flex?
  • A parent-child relationship in HTML occurs when one element contains another element inside it, and this becomes essential in Flexbox and Grid because the layout properties only apply to the direct child elements of the container.
  • Grid is two dimensional. Flexbox is a one-dimensional layout system that arranges items in either a row or a column, while CSS Grid is a two-dimensional layout system that arranges items in both rows and columns at the same time.
